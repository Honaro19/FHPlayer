Rule syntax

Use one branch per line: if pos >= 15 then vibrate(10), else if pos == 5 then vibrate(5) + rotate(3), else stop().

Variables use let, for example let level = pos * 0.5 + 2. You can use +, -, *, and : for division.

Supported variables: pos, index, atMs, currentMs, deltaMs. Supported operators: ==, !=, >=, <=, >, <. Join comparisons with and or or.

Commands must match the selected device capability, for example vibrate(10), rotate(4), pump(3), thrusting(12), suction(6), or stop().

Add a delay with a second action argument, for example vibrate(level, 0) + rotate(3, 250) or stop(500).

Mobile setups usually use direct HTTP with the phone IP and port, while desktop setups often work through the local Lovense bridge. Rules with + are only valid when the detected device supports multiple actions in parallel.

Notes

Videos and funscripts are paired by filename first. If no matching base name is found, remaining files are paired in their selection order.

If your funscript later contains values such as commandTemplate, shell, or timeoutSeconds, FHPlayer can use them as defaults.
