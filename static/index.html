Rule syntax

Use one branch per line: if pos >= 15 then vibrate(10), else if pos == 5 then vibrate(5) + rotate(3), else stop().

Variables use let, for example let level = pos * 0.5 + 2. You can use +, -, *, and : for division.

Target a specific selected device with [selector] before the action, for example [Nora Simulator] vibrate(10, 800) or [sim-nora] rotate(3, 800). Without a selector, the action applies to all selected devices.

Supported variables: pos, index, atMs, currentMs, deltaMs. Supported operators: ==, !=, >=, <=, >, <. Join comparisons with and or or.

Commands must match the shared capability set of the selected devices, for example vibrate(10), rotate(4), pump(3), thrusting(12), suction(6), or stop().

The second action argument is the duration in milliseconds, for example vibrate(level, 800) or rotate(3, 250). Use a separate delay(200) command to shift the whole branch.

In Lovense test mode, the device dropdown uses simulated devices, supports selecting one or more devices, and hides the host fields. In Lovense live mode, you can switch between multiple connection profiles for different users or hosts and select more than one detected device per profile.

Mobile setups usually use direct HTTP with the phone IP and port, while desktop setups often work through the local Lovense bridge. Rules with + are only valid when the selected devices share enough parallel Lovense functions.

Notes

Videos and funscripts are paired by filename first. If no matching base name is found, remaining files are paired in their selection order.
