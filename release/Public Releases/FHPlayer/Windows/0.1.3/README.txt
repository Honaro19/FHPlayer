FHPlayer 0.1.3 for Windows

Contents:
- FHPlayer-0.1.3-Setup.exe: per-user Windows installer
- FHPlayer-Portable-0.1.3.zip: portable bundle without installer
- LICENSE.txt: license and disclaimer
- CHANGELOG.txt: release summary
- SHA256SUMS.txt: checksums for the public files

Installation:
1. Run FHPlayer-0.1.3-Setup.exe for the standard Windows installation.
2. Or extract FHPlayer-Portable-0.1.3.zip and start FHPlayer.exe from the extracted FHPlayer folder.

Notes:

- Automatic update checks use GitHub Releases metadata and open the public GitHub release page.
- Update checks retrieve release metadata from GitHub. No personal data is collected or stored by the application.
